# AdvancedRCEditor

The editor includes completion and inline documentation for DWEM RC options, including
`map_predictor = true`. The value is the lowercase literal `true`; the option
defaults to false. While spectating, Map Predictor reads the watched player's
active RC rather than the viewer's RC.

## Get Parameters
### arce_rcfile
When you click the edit rc button, it will immediately overwrite the RC file.

### arce_append
When you click the edit rc button, it will add the text to the bottom of the RC file.

### arce_game_id
It will automatically set the game id to open.
